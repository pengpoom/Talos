## When to Use
- **提数据**："提取这篇的实验数据 / 数据集 / 指标 / baseline / 把结果记进库"（接在 `paper-reader` 读完之后最顺）。
- **比对**："这几篇在 <数据集/任务> 上谁最高 / 哪个 baseline / 各自指标多少"。

## 三层定位（衔接已有）
- **精读笔记** → 飞书文档（`paper-reader` 写的，叙述性）。
- **索引行** → 论文库 Base（`paper-library` 的元数据 + 链接）。
- **结构化实验数据** → 本技能：往**同一行**补实验字段，使其可筛/可比。

## A. 先确保论文在库
用 `paper-library` 找/建论文库 Base 并确认这篇**已入库**（有那一行）；没有就先走 `paper-library` 入库，再回来补数据。**不重复建行**——补的是已有行的字段。

## B. 给论文库 Base 补实验字段（一次性建字段）
用 `lark-base` 在论文库表加这些字段（已有就跳过）：
```
数据集/Benchmark(文本) / 任务(文本) / 主指标(文本，如 ASR/Acc/F1) / 主结果(文本，带数值)
/ baseline(文本) / 相对提升(文本) / 实验设置(文本，如模型/规模/条件) / 数据出处(文本，论文第几节/表几)
```

## C. 提取 + 回填（每篇）
1. **读全文**：`web_extract`/`lark-doc` 读论文（或用 `paper-reader` 已有的精读结果）。
2. **抽这些字段**（抽不到的**留空，别编**）：
   - **数据集/Benchmark**、**任务**：在什么数据上、做什么任务。
   - **主指标 + 主结果**：核心评测指标名 + **带数值**的结果（如 "ASR 从 78% 降到 12%"）。
   - **baseline + 相对提升**：对比的基线方法 + 相对它的提升/差距。
   - **实验设置**：模型/规模/关键条件。
   - **数据出处**：结果取自论文哪节/哪张表（**带出处，便于回查**）。
3. **回填**：用 `lark-base` 更新这篇在论文库的那一行（按标题/arXiv ID 定位）。
4. 回执："已补实验数据：<标题> —— 数据集 X、主指标 Y=<值>、baseline Z"。

## D. 比对查询
"这几篇在 <数据集> 上谁最高" → `lark-base` 按 数据集 筛 → 比 主指标/主结果 → 列出 标题 + 数值 + 出处，排序给结论。

## Pitfalls
- **数值必带出处**（第几节/表几）；论文没明说的指标/baseline **留空，绝不脑补编数**。
- 指标名/单位**尽量标准化**（ASR、Acc、F1…），同名才好比。
- **补字段不建新行**：先确认论文已在库（`paper-library`），只更新那一行。
- 不同论文口径不一致时，**如实标注口径差异**，别强行拉平比较。

## Verification
- 读完一篇 → "提取实验数据" → 论文库那一行多出 数据集/主指标/主结果/baseline 等字段，数值带出处。
- "这几篇在 X 上谁最高" → 按数据集筛、按主指标排序，给出带出处的排名。
